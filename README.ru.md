# DSP Hotword Trigger

Энергоэффективное **распознавание «OK Google» на Qualcomm Hexagon DSP для любого ассистента**, без приложений Google.
[English version](README.md)

## Какую проблему решает

На многих телефонах с Qualcomm есть модель фразы «OK Google» от производителя. Она работает на постоянно включённом
и экономичном DSP, но пользуется ею только приложение Google (как голосовая служба). В прошивках без сервисов Google
(или с microG):
- DSP-фразу никто не загружает;
- открытые ассистенты, например [Dicio](https://github.com/DicioTeam/dicio-android), вынуждены слушать свою фразу на
  процессоре с постоянно открытым микрофоном. Это тратит батарею и требует постоянного уведомления.

DSP Hotword Trigger загружает модель производителя на DSP через Android SoundTrigger. Услышав фразу, он запускает
приложение из **Настройки → Приложения → Приложения по умолчанию → Цифровой помощник**. Сам он не ассистент и роль
ассистента не занимает.

## Возможности

- «OK Google» работает при выключенном экране, с энергопотреблением DSP.
- **Запускает ассистента по умолчанию** наилучшим доступным способом:
  - **ассистент со своей голосовой службой (VIS):** открывает его голосовую сессию, в том числе поверх блокировки;
  - **ассистенты с `ACTION_VOICE_SEARCH_HANDS_FREE`:** открывает поверх блокировки. Это умеет
    [форк Dicio](https://github.com/Regloom/dicio-android/tree/lineage);
  - **[Dicio](https://github.com/DicioTeam/dicio-android):** открывает поверх блокировки через его действие пробуждения;
  - **любое другое приложение с `ACTION_ASSIST`:** запускает после разблокировки.
- **Только голос владельца (по желанию).** Голос проверяется на телефоне моделью 3D-Speaker CAM++ через
  [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) по звуку, который записал DSP. Отсекает других людей, храп и
  голоса из телевизора. С загруженной моделью проверка занимает около 0,3 с.
- **Настройки и переключатель:** пункт в Настройки → Система и плитка в шторке. Интерфейс на английском и русском.
- **Приватность:** нет доступа к сети, данные не покидают телефон.

## Требования

- Процессор Qualcomm, SoundTrigger HAL которого распознаёт ключевые фразы, и приложение производителя
  `com.android.hotwordenrollment.xgoogle` (фраза «X Google», id 101). Есть на многих телефонах Qualcomm, например Xiaomi.
- Android 14 и новее, arm64. Проверено на Poco F6 (Snapdragon 8s Gen 3) с LineageOS 24 (Android 17).
- **APK должен быть подписан платформенным ключом прошивки** (нужны signature-права). То есть подходит для
  собственной сборки прошивки или прошивки, подписанной тестовыми ключами AOSP.

## Установка

### В сборку прошивки

1. Добавьте репозиторий в дерево, например в `.repo/local_manifests/dsp-hotword.xml`:
   ```xml
   <manifest>
     <remote name="github-dsphotword" fetch="https://github.com/" />
     <project path="packages/apps/DspHotwordTrigger" name="Regloom/dsphotword"
              remote="github-dsphotword" revision="main" />
   </manifest>
   ```
2. Добавьте приложение в makefile устройства:
   ```make
   PRODUCT_PACKAGES += DspHotwordTrigger
   ```
3. **По желанию:** задайте язык модели производителя через overlay `config_hotwordLocale`, например `ru-RU`. По
   умолчанию используется язык системы, запасной — `en-US`. Фраза во всех языках одна, «OK Google»: язык лишь выбирает
   записанную копию модели.

### Модулем KernelSU (root, прошивка с известным платформенным ключом)

Готовые сборки: [Releases](https://github.com/Regloom/dsphotword/releases) или артефакты
[workflow сборки](https://github.com/Regloom/dsphotword/actions). **Они подписаны открытым тестовым платформенным ключом
AOSP**, поэтому работают только на прошивках, подписанных тестовыми ключами (большинство самосборных и многие
неофициальные). Для другой прошивки соберите сами с её платформенным ключом:

```sh
# с собранным деревом AOSP/LineageOS (его инструменты сборки, framework.jar и платформенный ключ)
LINEAGE_TREE=/путь/к/собранному/дереву ./build-apk.sh
# или с Android SDK (build-tools, platforms;android-36) и JDK 17+
ANDROID_HOME=/путь/к/sdk PLATFORM_KEY=/путь/к/platform ./build-apk.sh   # platform.pk8 + platform.x509.pem
./build-ksu-module.sh
adb push build/DspHotwordTrigger-KSU-*.zip /data/local/tmp/
adb shell su -c 'ksud module install /data/local/tmp/DspHotwordTrigger-KSU-*.zip'
```

Чтобы сборки GitHub в форке подписывались своим ключом, задайте секреты репозитория `PLATFORM_PK8_BASE64` и
`PLATFORM_X509_BASE64` (`base64 -w0 platform.pk8`). Тег `v*`, совпадающий с `version` в `ksu-module/module.prop`,
публикует релиз.

Затем в профиле приложения «DSP Hotword Trigger» в KernelSU **выключите «Отмонтировать модули»**, иначе приложение
не видит свой APK и падает. Перезагрузите телефон. Приложение постоянное (persistent), поэтому обновления тоже
вступают в силу после перезагрузки.

## Использование

1. Выберите ассистента: **Настройки → Приложения → Приложения по умолчанию → Цифровой помощник**, например Dicio.
2. Скажите «OK Google».
3. По желанию: в **Настройки → Система → Голосовая активация «OK Google»** запишите образец голоса (5 раз
   «OK Google»), чтобы ассистент запускался только на ваш голос.

Журнал: `adb logcat -s DspHotword`. Кнопка «Действие» модуля KernelSU показывает диагностику.

## Ограничения

- Qualcomm PAL SoundTrigger HAL не применяет порог уверенности: он возвращает запрошенное значение и реальной
  уверенности не сообщает. Поэтому ложные срабатывания отсекает проверка голоса, а не DSP.
- **Проверка голоса** настроена на небольшом наборе записей. Если она отклоняет вас или пропускает других, поправьте
  «Строгость проверки голоса».
- **При «Отмонтировать модули» в KernelSU** Settings не может прочитать ресурсы APK из модуля:
  - у пункта нет иконки;
  - его название приходит от приложения через ContentProvider.

Заметки по исследованию (права, SELinux, ограничения DSP): [docs/NOTES.md](docs/NOTES.md).
